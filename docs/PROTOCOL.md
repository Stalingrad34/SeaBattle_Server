# SeaBattle: сеть

## Состояние

Источник структуры — серверный `src/rooms/schema/MatchState.ts`: Schema и @type, как в SlapBattles.
Из папки Server выполните `npm run export`, чтобы обновить C# в `Assets/Game/Scripts/Multiplayer/Generated`. Генерируемые файлы вручную не редактируются.

Colyseus автоматически передаёт начальное состояние и изменения через OnStateChange.
MatchState содержит фазу, очередь, revision, turnId, deadlineMs и правила.
StateView передаёт каждому игроку только его PlayerState: собственные корабли и результаты выстрелов.
Клетки чужого корабля раскрываются только при его потоплении.

## Сообщения

Клиент отправляет `room.Send("fire", command)`, сервер принимает через `onMessage("fire", ...)`.
Ответ — `client.send("commandResult", result)`. Объекты сериализует сам Colyseus.

- FireCommand: commandId, turnId, x, y.
- CommandResult: commandId, turnId, revision, status (applied/rejected), reason.
- error: строка invalid_request при неверном формате команды.

Игрок определяется по client.sessionId. Передавать playerId, connectionId или matchId в команде не требуется.
commandId — 1–128 латинских букв, цифр, дефисов или подчёркиваний; turnId — положительное целое; координаты — с нуля.

Точный повтор принятой команды возвращает прежний результат без повторного выстрела.
Изменённая команда с тем же ID отклоняется с command_conflict.
Другие причины отказа: unauthorized, match_not_started, match_finished, wrong_turn, turn_expired, out_of_bounds, already_shot.
Отклонённые команды пока не кешируются.

Результат и патч состояния могут прийти в разное время: revision ответа связывает их.
deadlineMs использует монотонное серверное время, не UTC.

## Текущее поведение

Есть одна комната battle на двух игроков. Второй игрок запускает матч; первый ход выбирается случайно.
Сервер управляет расстановкой, выстрелами, таймером и победой. Выход из начавшейся партии пока означает поражение.
Переподключение и восстановление остаются этапом 5.

Один экземпляр Unity — один игрок. Запуск приложения показывает попап без соединения.
Кнопки создания и присоединения по восьмисимвольному имени пока не подключены.
